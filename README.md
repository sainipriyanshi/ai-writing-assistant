# AI Writing Assistant — Week 1

A Python CLI application built with the Gemini API.

## Mini Project Features

- Blog writing
- Email drafting
- Code explanation
- Social media post generation
- Temperature control
- Markdown, plain text, JSON, and table output formats

## Setup

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```env
GOOGLE_API_KEY=your_gemini_api_key
```

## Run

```bash
python app.py
```
